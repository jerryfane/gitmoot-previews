# item-003: Gitmoot install/get-started page

Create a Vue 3 + Vite get-started page for Gitmoot.

The page should help a first-time user install Gitmoot, verify the CLI, install
the Codex or Claude plugin, create a first agent template, and run a simple
agent request. Keep the page practical and short enough to follow while working
in a terminal.

Primary action: copy the install command.
Secondary action: open the GitHub repository.
