# item-001: Gitmoot developer landing page

Create a Vue 3 + Vite landing page for Gitmoot aimed at software developers
who already use AI coding agents.

The page should explain that Gitmoot is a local-first coordinator for AI agents
working across repositories, GitHub PR comments, goals, reviews, and reusable
agent templates. It should make the workflow feel concrete: install Gitmoot,
create or subscribe agents, route work through GitHub comments or local agent
commands, and keep humans in control of review and merge decisions.

Primary action: install Gitmoot.
Secondary action: read the agent skill.
