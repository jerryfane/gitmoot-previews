# item-002: Gitmoot SkillOpt explainer page

Create a Vue 3 + Vite landing page that explains Gitmoot SkillOpt to technical
users.

The page should make the A/B feedback loop easy to understand: create a
template, generate baseline and candidate outputs, publish clickable previews,
collect human preference feedback, export a training package, run optimization,
then import a candidate template for promotion or rejection.

Primary action: start a review run.
Secondary action: inspect the exchange contract.
